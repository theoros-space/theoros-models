# Dataset card: synthetic

| Field | Value |
|---|---|
| Source | Generated by `theoros_models.data.synthetic` in this repository |
| Version | Defined by the repository commit; the generator is deterministic in its seed |
| License | Theoros Open License 1.0, as the generating code |
| Commercial use allowed | yes |
| Sensor and level | Any valid sensor profile; simulated TOA reflectance |
| Tasks and labels | cloud (clear, thick, thin, shadow), land and water, vessels (centre, length, width), active fire |
| Size | Generated on demand; nothing is stored |
| Checksum | Not applicable: samples are a function of profile, tile size and seed |
| Splits | None; tests choose disjoint seeds where they need separate sets |
| Adapter | `SyntheticDataset` |

## Purpose

Exercising the pipeline in tests and CI without downloading data: tiling,
augmentation, packing, sampling, losses and a training epoch on every tier.

## Construction

Six analytic material spectra (water, vegetation, soil, cloud, vessel hull,
active fire) are integrated over each band's spectral response. A scene is a
layout of smooth random fields: water against land, vegetation against soil,
small fire discs on land, rectangular vessels on water, thick and thin cloud,
and cloud shadow displaced from thick cloud. Thin cloud blends 45 percent
cloud over the surface, shadow scales the surface by 0.35, and Gaussian noise
of 0.004 reflectance is added. Land and water and fire are unlabelled (255)
under thick cloud, and vessels under thick cloud are not annotated.

## Known issues

- The spectra are smooth approximations, not measured library spectra.
- Scenes have no terrain, atmosphere variation, sun geometry or sensor
  artefacts.
- Results on synthetic data say nothing about accuracy on real imagery and
  must never be reported as such.
